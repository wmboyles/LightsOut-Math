	\section{Definitions}
	Let \textit{Lights Out} be a game played on a simple graph $G = (V,E)$ where clicking a vertex $v$ toggles the on/off state of $v$ and its neighbors.
	One wins the game by finding a sequence of clicks that turns off all the lights.

	\begin{definition}
		The Most Clicks Problem (MCP) asks, for playing on some graph $G$, what is the most clicks needed to solve any solvable starting configuration, assuming that one solves each configuration in as few clicks as possible.
	\end{definition}
	That is, what is the most number of moves one needs to be able to solve any solvable initial configuration?
	This question is akin to looking for ``God's Number'' on a Rubik's Cube.

	\begin{definition}
		Let $d(n) = \dim{\ker{(A + I)}}$ over the field $\Z_2$ where $A$ is the adjacency matrix of $G$ an $n \times n$ grid.
	\end{definition}
	You may also hear $d(n)$ referred to as the \textit{nullity} of the $n \times n$ grid.
	The right-hand side of the equation applies for any graph, not just grids.
	Elements of the null space correspond to sets of clicks that have no net effect on the states of the vertices when applied.
	These elements also correspond exactly to subsets of $V$ such that all vertices have an even number of elements from the subset in their closed neighborhood (themselves and their neighbors).
	Thus, these elements of the null space may be referred to as \textit{null patterns}, \textit{quiet patterns}, or \textit{even dominating sets}.

	\begin{definition}\label{def-polys}
		Let $F_n(x)$ be the polynomial in the ring $\Z_2[x]$ such that
		\begin{equation*}
			F_n(x) = \begin{cases}
				0 & n = 0 \\
				1 & n = 1 \\
				x F_{n-1}(x) + F_{n-2}(x) & n > 1
			\end{cases}.
		\end{equation*}
	\end{definition}
	These polynomials become useful in calculating $d(n)$.
	It is known that
	\begin{equation*}
		d(n) = \deg{\gcd{\left(F_{n+1}(x), F_{n+1}(x+1)\right)}}.
	\end{equation*}

	\section{Conjectures}
	The mixed-prime formulas formerly listed here are now theorems.
	The finite-support truncation theorem in
	\texttt{tex/multiprime\_stabilization/multiprime\_stabilization.tex}
	reduces every fixed odd prime support to finitely many exponent vectors, and exact computations settle the previously listed two-prime formulas.
	The same theorem proves that $d(a^k-1)$ is eventually constant for every odd positive integer $a$, so the former eventual-constancy conjecture has also been removed.

	We also have conjectures about $d(p^k - 1)$ for $p$ a prime.
	\begin{conjecture}\label{d(p^k-1)=d(p-1)}
		Let $p$ be a Wieferich prime.
		Then for every $k\geq1$,
		\begin{equation*}
			d(p^k - 1) = d(p-1).
		\end{equation*}
	\end{conjecture}
	The formula is already proved for every non-Wieferich prime.
	More generally, if
	\begin{equation*}
		c_p=v_p\!\left(2^{\operatorname{ord}_p(2)}-1\right),
	\end{equation*}
	then prime-power stabilization proves
	\begin{equation*}
		d(p^k-1)=d(p^{c_p}-1)
		\qquad(k\geq c_p).
	\end{equation*}
	The two known Wieferich primes, 1093 and 3511, both have $c_p=2$, and exact polynomial GCD computations give
	\begin{equation*}
		d(p^2-1)=d(p-1)=0
	\end{equation*}
	for both.
	Thus the conjecture holds for every currently known Wieferich prime; any counterexample requires a presently unknown one.

	\begin{proposition}\label{prime-mad-characterization}
		Let $p>3$ be prime and define
		\begin{equation*}
			R_p=
			\left\{
				\zeta+\zeta^{-1}:
				\zeta\in\overline{\mathbb{F}}_2,
				\operatorname{ord}(\zeta)=p
			\right\}.
		\end{equation*}
		Then
		\begin{equation*}
			d(p-1)=2\left|R_p\cap(R_p+1)\right|.
		\end{equation*}
		In particular, $d(p-1)\neq0$ if and only if there exist nontrivial $p$th roots of unity $t,s$ satisfying
		\begin{equation*}
			1+t+t^{-1}+s+s^{-1}=0.
		\end{equation*}
		Equivalently, $p$ is a prime mad number in the terminology of \textit{Button Madness}.
	\end{proposition}

	Blokhuis proved the necessary condition
	\begin{equation*}
		d(p-1)\neq0
		\quad\Longrightarrow\quad
		\rho_2(p)\leq\sqrt p,
		\qquad
		\rho_2(p)=\min\{r>0:2^r\equiv\pm1\pmod p\}.
	\end{equation*}
	The converse is false: $\rho_2(241)=12<\sqrt{241}$, but $d(240)=0$.
	On the positive side, every Mersenne prime greater than 7 and every Fermat prime greater than 3 has nonzero $d(p-1)$.

	\begin{problem}
		Give a purely arithmetic characterization of the primes $p$ for which
		\begin{equation*}
			R_p\cap(R_p+1)\neq\varnothing.
		\end{equation*}
	\end{problem}

	\begin{conjecture}
		There are infinitely many primes $p$ for which $d(p-1)\neq0$.
	\end{conjecture}

	We know that $d(n) = 26$ is the smallest even impossible value for $d$.
	We also know that if $a$ is an impossible even value of $d$, then $2a+2$ is also impossible.
	We would like to better classify and understand impossible values.
	Let $I$ be the set of even values that are never values of $d(n)$.
	Call an element of $I$ a \textit{seed} if it is not obtained from a smaller impossible value by the recurrence $a\mapsto2a+2$.
	\begin{conjecture}
		The following are true:
		\begin{enumerate}
			\item $34 \in I$ (implies $70, 142, 286, \ldots \in I$)
			% 52 \in I because d(8434) = 52
			% 68 \in I because d(10794) = 68
			\item $I$ has infinitely many seed values.
		\end{enumerate}
	\end{conjecture}

	Our method for solving the MCP for nullity 2 grids involved getting an exact solution to an integer linear program by noticing all constraints could be tightly satisfied at once.
	We proved that every nullity 2 grid has size $6k-1$ and that its MCP value is $26k^2-12k+1$.
	However, this does not seem to work for higher nullities.
	We suspect that the answer to the MCP is still a parabola though.
	Thus, we can calculate the answer to the MCP for 3 boards of the same nullity in the same family (i.e. size is same mod some number) and derive the parabola.
	\begin{conjecture}
		Regarding the answer to the MCP for an $n \times n$ grid,
		\begin{enumerate}
			\item
				If $n = 10k - 6$ and $d(n) = 4$, then the answer to the MCP is $17k^2 - 10k$.
			\item
				All nullity 4 grids are of size $10k - 6$
			\item
				If $n = 24k - 13$ and $d(n) = 6$, then the answer to the MCP is $88k^2 - 24k + 1$.
			\item
				All nullity 6 grids are of size $24k-13$.
			\item
				If $n = 40k - 31$ and $d(n) = 8$, then the answer to the MCP is $60k^2 - 20k - 3$.
			 \item
				If $n = 34k - 18$ and $d(n) = 8$, then the answer to the MCP is $161k^2 - 34k - 3$.
			 \item
				If $n = 60k - 31$ and $d(n) = 10$ then the answer to the MCP is $506k^2 - 60k - 3$.
			 \item
				All nullity 10 grids are of size $60k - 31$.
			 \item
				If $n = 340k - 256$ and $d(n) = 12$, then the answer to the MCP is $3761k^2 - 169k - 13$.
			 \item
				All nullity 12 grids are of size $340k - 256$.
			 \item
				$\ldots$
		\end{enumerate}
	\end{conjecture}
	Notice that there are different ``families'' associated with each nullity.
	These families correspond to a certain size of board.
	Notice that one nullity might have multiple families.
	It seems that the smallest board in each family appears in OEIS sequence A118142.
	We suspect that the parabolas giving the answer to the MCP for a given family always have integer coefficients.

	We also have a conjecture about the maximum values of $d(n)$.
	\begin{conjecture}
		\begin{equation*}
			d(n) \le \frac{4(n+1)}{5},
		\end{equation*}
		with equality if and only if $n = 5 \cdot 2^k - 1$.
	\end{conjecture}
	The family $n=5\cdot2^k-1$ is already known to attain equality.
	The unresolved parts are the global upper bound and the exclusion of any other equality cases.
	As far as we know, the only other proof on bounds of $d(n)$ known to date is that $d(4) = 4$ is the only case where $d(n) = n$.
